# Code for the paper: **Readability Formulas, Systems and LLMs are Poor Predictors of Reading Ease**

## Quick Start

1. `conda env create -f env.yml`
   - `conda activate readability_env` for running Python scripts

### Run

1. **Compute Correlations:**  
   - Run `src/Correlations/run.py` to calculate all analysis and generate Figures.

2. **Readability Formula Resources:**  
   - Links to the resources used for calculating readability formulas are provided in SI Appendix.
